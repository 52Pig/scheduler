# ADR 0003: 由用户定义 DAG 和触发计划

- 状态：Accepted
- 日期：2026-11-19
- 范围：依赖关系和工作流触发

## 背景

调度器需要支持任意业务流程，包括空根节点、多个分支和汇合。硬编码 extract/transform/report 等阶段会限制应用范围并使框架承担业务模型。

## 决定

任务 ID、名称和直接父任务由用户定义。依赖图必须无环，当前每个图只允许一个根；计划可配置在根或下游节点。工作流运行 ID 关联一次 DAG 执行，每个节点运行 ID 记录具体尝试。

## 后果

- 新任务类型不需要修改调度器代码。
- 当前禁止跨根汇合，计划下游节点检查其祖先在各自时区当天成功。
- 手动运行的 `self` 和 `downstream` 范围必须在 API、UI、CLI 中保持一致。
- DAG 语义变化必须同步更新 `dependency-workflows.md`、API/任务指南和行为测试。

## 考虑过的方案

- 内置业务阶段枚举：无法支持用户任意工作流。
- 允许任意跨根 join：当前没有共同触发、历史匹配和运行关联规则，容易产生含糊调度。
